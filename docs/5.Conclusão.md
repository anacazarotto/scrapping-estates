# Linha do tempo do modelo

## 1. Levantamento inicial

- Foram inspecionados os HTMLs e JSONs das fontes coletadas.
- Foi mapeada a estrutura comum dos registros no SQLite.
- Foi identificado que os bancos `imoveis_dd_mm_aaaa.db` tinham o mesmo schema.

## 2. Unificação dos bancos

- Criado o comando `unify` em `scripts_predict/imoveis_ml.py`.
- Os bancos `imoveis_??_??_????.db` passaram a ser consolidados em `imoveis_unificado.db`.
- A unificação usa o `codigo` extraído do `id` como chave principal.
- O registro consolidado preserva os `id` de origem, os bancos de origem e a quantidade de ocorrências.

## 3. Normalização dos dados

- Criado o banco `imoveis_normalizados.db`.
- Imóveis sem preço passaram a ser descartados.
- Campos nulos numéricos passaram a ser tratados como `0`.
- `area_total` e `area_privada` passaram a ser mantidas separadamente.
- O tipo do imóvel passou a ser padronizado por similaridade.

## 4. Primeiro benchmark geral

- Foram testados:
  - Regressão Linear
  - Ridge
  - Lasso
  - Random Forest
  - Gradient Boosting
  - XGBoost
  - CatBoost
- Foi gerado o relatório `reports/modelo_comparativo.md`.
- O resultado mostrou baixo poder explicativo no conjunto completo.

## 5. Foco em Casas e Apartamentos

- Foi criado o experimento `reports/experimentos_casas_apartamentos.md`.
- O filtro para Casas/Apartamentos melhorou o cenário em relação ao conjunto completo.
- Separar por tipo não trouxe ganho consistente.
- Remover outliers melhorou bastante os erros.

## 6. Tuning de hiperparâmetros

- Foi criado o experimento `reports/tuning_casas_apartamentos.md`.
- O melhor cenário foi:
  - Casas/Apartamentos
  - sem outliers
  - `Gradient Boosting`
  - alvo em `preco`
- Esse cenário virou a baseline do projeto.

## 7. Baseline final

- O baseline padrão passou a ser salvo em `modelos/preco_imovel_modelo.pkl`.
- O comando `train-price-model` passou a treinar esse baseline.
- O comando `predict-price` passou a usar esse arquivo como padrão.
- O treino final foi executado com o Python do `venv` para evitar incompatibilidade de versão do pickle.

## 8. Resultado final

- O baseline final ficou estável para previsão.
- O fluxo atual é:
  1. `unify`
  2. `normalize`
  3. `train`
  4. `predict`
